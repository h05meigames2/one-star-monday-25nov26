Entry for the make.fun **One Star for Monday** bounty: a one-star restaurant review of Monday itself. No table at nine, coffee that tastes like burnt emails, a waiter who vanishes for eight hours — and the bill turns out to be Monday. Short enough to retype into the group chat without trimming a word.

## Run

```bash
python3 main.py
```

This writes the one-line review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
